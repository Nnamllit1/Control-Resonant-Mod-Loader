# CRML v0.1.0-alpha.4

CONTROL Resonant Mod Loader is a shared runtime for sandboxed WebAssembly mods.
This experimental release supports the game build recorded in `compatibility.json`.

## Download

**To use mods, download `crml-runtime-v0.1.0-alpha.4-windows-x64.zip`.**
It contains the loader, runtime dependencies and installation instructions.
Install individual mods separately using their own instructions.

**To write mods, download `crml-sdk-v0.1.0-alpha.4-windows-x64.zip`.**
It contains headers, example source, a WAT compiler and a standalone host.
Keep the SDK outside the game folder.

GitHub's Source code downloads are for building CRML itself. Players do not need them.

## Install

1. Close CONTROL Resonant and extract the runtime ZIP with **Extract All**.
2. In Steam, right-click the game and choose **Manage > Browse local files**.
3. Copy the extracted contents beside `CONTROLResonant.exe`. The new
   `xinput1_4.dll` and `crml` folder should sit beside the game executable.
4. Add compatible mods, then start normally through Steam or double-click
   `CONTROLResonant.exe` with Steam running.

No compiling or separate launcher is needed. For updates and removal, read
`README-CRML.txt` inside the ZIP or the [installation guide](https://crml.nnamllit.de/installation/).

## Changes

- Two framework downloads: runtime for players and SDK for mod authors.
- The runtime no longer installs the hello example; it remains in the SDK.
- Documentation separates installation, mod authoring and contributor research.
- Mod authoring starts with the downloaded SDK instead of a native source build.

Gameplay support remains experimental and limited to the supported executable
fingerprint. Individual mods define their own features, controls and requirements.
Direct Lua source mods and arbitrary native mod DLLs are not supported.
