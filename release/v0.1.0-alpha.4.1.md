# CRML Alpha 4.1

This compatibility update adds a choice for untested game builds and changes keyboard polling to avoid interfering with other mods' hotkeys.

- An unrecognized executable opens a native Windows prompt confirming that CRML loaded. No mods or gameplay hooks start until you continue. You can leave CRML disabled and optionally remember either choice for that exact executable.
- Hook signature checks remain required after approval. An untested build may still behave incorrectly or crash; this release does not certify every storefront or edition.
- CRML reads a cached keyboard snapshot instead of repeatedly calling `GetAsyncKeyState`, avoiding consumption of the shared pressed-key bit used by other polling code. Flight still suppresses its movement controls while active. Compatibility with individual third-party mods still needs testing.
- The proxy starts CRML on the first forwarded XInput call, rather than requiring one particular export to be called. Missing runtime dependencies produce a Windows error dialog.

Download **`crml-runtime-v0.1.0-alpha.4.1-windows-x64.zip`** to use mods. Close the game, extract the ZIP, and copy its contents beside `CONTROLResonant.exe`, replacing CRML's files and keeping your installed mods. Launch using your normal storefront or launcher. The **SDK** download is for mod authors.

**The runtime alone does not include a gameplay mod or an in-game panel.** Install your chosen mod separately. Replacing `compatibility.json` does not enable a mod or change engine addresses.

To reset a remembered compatibility decision, remove `crml/compatibility-choice.txt` with the game closed. Logs are in `crml/crml.log`. Lua source support remains separate development work and is not included in this release.
