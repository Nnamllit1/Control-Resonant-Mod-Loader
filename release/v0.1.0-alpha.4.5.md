# CRML Alpha 4.5

Adds compatibility with CONTROL Resonant **0.564.629.5**. Download
**`crml-runtime-v0.1.0-alpha.4.5-windows-x64.zip`** and follow the
[update instructions](https://crml.nnamllit.de/installation/). Keep your existing
compatible mods; the separate SDK archive is for mod developers.

- Updates native code addresses, data references and hook signatures for this
  executable. All three previously supported executable profiles remain available.
- Preserves the released Wasm ABI 1 and SDK interfaces. Existing compatible mods
  do not need recompiling; this update adds no SDK features.
- Retains executable, middleware and hook checks. The checked physics/UI
  middleware, stock UI resources and boundary-recovery script are unchanged.

The new executable SHA-256 is
`9f56611d767c9227a8a1b250c01acf9478b50933c65f86a1e044fcc53df67cb1`.
Other executable variants still use the untested-build consent dialog, which
links to the [release downloads](https://github.com/Nnamllit1/Control-Resonant-Mod-Loader/releases).

Native mappings and packaged runtime behavior are checked offline. Gameplay
on this executable has not yet been verified; native gameplay services remain
experimental. This compatibility release is based on Alpha 4.4 and does not
include the in-development engine-access bridge.
