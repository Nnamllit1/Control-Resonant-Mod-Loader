# CRML Alpha 4.3

Adds an executable profile for CONTROL Resonant **0.564.208.5**, while retaining the previous build's profile. Update the CRML runtime after installing this game update; existing ABI 1 mods do not need recompiling.

- Movement, recovery, visibility, physics, camera observation, native UI and startup playback use the addresses and signatures for the identified executable.
- The native UI adapter recognizes the updated game UI document. Executable, middleware and hook checks remain in place.
- Wasm interfaces and the Alpha 4.2 SDK contracts are unchanged. Gameplay services remain experimental.
- The SDK's optional native Mods page keeps Options input ownership while open, preventing gameplay controls from leaking through the settings menu. Only Mods is highlighted while selected, and closing it restores the stock settings controls.

The unknown-build prompt also links directly to CRML's GitHub releases:

- **Check for CRML updates on GitHub** opens the releases page in your browser. The prompt stays open and the link does not approve mods or change your remembered choice.
- The prompt explains that a game update or different edition can cause the mismatch. Close the game before installing a newer runtime; reinstalling the same version does not add compatibility.
- If the browser cannot open, the prompt displays the download address. The fallback Windows dialog also includes that address.

Other executable variants still require explicit consent. Matching a displayed game version alone does not establish that an executable has the same native layout.

Players should download **`crml-runtime-v0.1.0-alpha.4.3-windows-x64.zip`** and keep their installed mods. The separate **SDK** includes the current headers, examples and developer tools.

See [installation](https://crml.nnamllit.de/installation/) and [troubleshooting](https://crml.nnamllit.de/troubleshooting/).
