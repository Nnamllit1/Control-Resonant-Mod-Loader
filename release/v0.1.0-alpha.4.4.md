# CRML Alpha 4.4

Adds an executable compatibility profile for CONTROL Resonant **0.564.478.0**. Download **`crml-runtime-v0.1.0-alpha.4.4-windows-x64.zip`** and follow the [update instructions](https://crml.nnamllit.de/installation/). Keep your installed mods.

- Adds native addresses and signatures for the updated game executable. Previous executable profiles remain supported.
- Keeps the existing Wasm ABI 1 and SDK interfaces unchanged; existing compatible mods do not need recompiling. This release contains no new SDK features.
- Checks that every advertised executable profile is included in the packaged runtime and release metadata.
- Retains executable fingerprint, middleware and native hook checks. Gameplay services remain experimental; live gameplay on this build has not yet been verified.

The new profile identifies executable SHA-256 `4f6596b08bb5bc7fe4150cf5b9f71d7bae87eea02d66627c03a5e05ffe84ea62`. A matching displayed game version alone does not establish native compatibility; other executable variants still require explicit consent.

See [installation](https://crml.nnamllit.de/installation/) and [troubleshooting](https://crml.nnamllit.de/troubleshooting/).
