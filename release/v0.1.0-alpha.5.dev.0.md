# Runtime and SDK source checkpoint

This is a development source checkpoint. Alpha 4.5 remains the published player
download; this checkpoint does not publish a replacement runtime archive.

Mod authors can use the expanded SDK sources for persistent settings and storage,
configurable input actions, native feedback and tutorials, searchable lists, and
map drawing. These additions require a matching runtime built from this source;
they are not supplied by the Alpha 4.5 download. The maintained examples show
how to compose these services. The Mods page includes searchable mod selection, and route markers support editing
and persistence through the game's map view.

The author CLI supports project creation, compilation, offline host checks and
deterministic scenarios. CI builds the runtime, checks the native UI fixtures and
exercises an extracted SDK. Offline checks establish host behavior, not arbitrary
engine compatibility; native operations remain limited to their reviewed builds
and documented contracts. Existing ABI 1 imports retain their signatures.

General engine-object access is not included. Physics bridge research is deferred.
Story-area airborne transitions remain a known limitation; this checkpoint does
not claim a fix. Lua source authoring and independent camera ownership remain
separate work. This is not API 1.0 completion.

See the [SDK contract status](../docs/sdk-contracts.md),
[mod-author guide](../docs/developing.md), and
[testing guide](../docs/mod-testing.md) for supported behavior and limitations.
