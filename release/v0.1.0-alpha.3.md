# CRML v0.1.0-alpha.3

An experimental Windows x64 runtime for sandboxed Wasm mods, with a playable
noclip and free-flight example for the fingerprinted CONTROL Resonant build.

- **Runtime:** install CRML, then add the mods you want.
- **Noclip:** the movement mod and enable marker; requires the matching runtime.
- **Noclip bundle:** the runtime and movement mod together.
- **SDK:** headers, example source, and standalone Wasm tools for mod authors.

Flight starts off. Use **F6** to toggle, **WASD** to move, **Space/Ctrl** to rise or
descend, and **Shift** to fly faster. **Insert** hides or shows the redesigned panel
without changing flight. **Esc** or focus loss cancels flight.

The player moves through geometry; the camera remains controlled by the game.
Return to safe ground before turning flight off. Unknown game fingerprints refuse
gameplay support, and game updates may require a new runtime. Direct Lua source
mods and arbitrary native mod DLLs are not supported by this release.

Read the installation/removal instructions inside the archive before copying
files. Keep custom mods when upgrading and do not overwrite a different XInput
proxy. SHA-256 checksums and package metadata accompany the downloads.

[Documentation and supported API](https://crml.nnamllit.de/)
