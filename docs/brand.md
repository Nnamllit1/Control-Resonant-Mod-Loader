# Brand assets

Use these assets when linking to CONTROL Resonant Mod Loader, crediting its research, or identifying mods and tools built with CRML. The angular C, floating diamond and resonance mark form the project symbol.

All variants are SVGs with outlined lettering: they scale without requiring fonts or external resources. Icons, horizontal logos and stacked logos have transparent backgrounds. The favicon uses a fixed dark tile so it stays legible in browser tabs.

## Favicon and usage

![CRML favicon](assets/brand/favicon.svg){ width="64" }

[Download the favicon](assets/brand/favicon.svg). Leave clear space around the mark, preserve its proportions, and choose a variant with good contrast against its background. When identifying a compatible mod, use wording such as “Built with CRML” without implying that the mod is an official project release.

CRML is an independent community project and is not affiliated with Remedy Entertainment.

Contributors can regenerate the complete set with `python tools/generate_brand.py`. The generator also keeps `assets/logo.svg`, used by the README and site header, in sync with the favicon.
